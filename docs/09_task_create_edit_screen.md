# 09 タスク作成/編集画面

## 概要
タスク・サブタスクの新規作成および編集を行う画面を実装する。サブタスクの追加・削除・並び替え・重み調整をこの画面で完結させる。

## 詳細要件
- タスクタイトルの入力フォームを実装する
- サブタスクの追加・削除・並び替えUIを実装する
- サブタスクの重み調整UI(デフォルト均等割り、手動で数値変更も可能)を実装する
- 保存時に02(タスク管理)・03(サブタスク管理)の機能を呼び出す
- タスク一覧画面・タスク詳細画面からの導線を接続する
