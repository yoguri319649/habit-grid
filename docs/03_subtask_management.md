# 03 サブタスク管理(追加・編集・削除・重み設定)

## 概要
タスクを複数のサブタスクに分解し、各サブタスクの重み(全体への貢献度%)を管理する機能を実装する。重みはデフォルトで均等割りとし、手動調整も可能にする。

## 詳細要件
- サブタスクの追加(名称入力)
- サブタスクの編集(名称変更)
- サブタスクの削除
- サブタスクの並び替え(並び順の保存)
- サブタスク作成時、重みをデフォルトで均等割りに自動設定する
- サブタスクの重み(%)を手動で数値変更できる
- 重みの合計が100%になるようなバリデーション/自動調整ロジック
  - → 追加時(`createSubTask`)と削除時(`deleteSubTask`)は自動調整(均等割り/比率配分)で常に合計100%を維持する
  - → 手動での重み変更(`updateSubTaskWeight`)は他のサブタスクに影響しない(自動調整しない)。合計が100%かどうかは09の編集画面の完了操作時にバリデーションする
