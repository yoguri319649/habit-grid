# 06 コントリビューショングラフ表示

## 概要
GitHubのコントリビューショングラフのように、タスク単位の自己申告時間の合計を日別の濃淡で可視化する機能を実装する。react-native-svgによる自前描画を行う。

## 詳細要件
- タスクごとの直近の取り組み時間(TimeLog)を日別に集計する
- 日ごとの合計時間に応じてマス目の濃淡を変化させる(GitHub風ヒートマップ)
- react-native-svgを用いた自前のグラフ描画コンポーネントを実装する
- タスク詳細画面に統合表示する
- グラフの縦軸(曜日)・横軸(月)がわかるようラベルを表示する(縦軸: 月・水・金、横軸: 月が変わる週に「N月」)
