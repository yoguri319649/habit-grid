# 02 タスク管理(CRUD・完了操作)

## 概要
タスクそのものに対する作成・編集・削除・完了操作を実装する。タスク一覧・詳細・作成編集の各画面から呼び出される中核ロジック。

## 詳細要件
- タスクの新規作成(タイトル入力)
- タスクの編集(タイトル変更)
- タスクの削除(関連するサブタスク・時間記録も削除)
- タスクの完了操作(完了状態のトグル)
- 上記操作に対応するDBアクセス関数(01のデータ層を利用)
