# 05 取り組み時間の自己申告記録(時間チップ)

## 概要
「今日どのくらい進めた?」に対し、15分/30分/1時間/それ以上のワンタップ時間チップで自己申告記録できる機能を実装する。コントリビューショングラフの元データとなる。

## 詳細要件
- タスク詳細画面に時間チップ(15分/30分/1時間/それ以上)を表示する
- チップタップでその日の自己申告時間(分)をTimeLogとして記録する
- 同日に複数回入力した場合の扱い(加算/上書き)を定義する
- 記録した時間はタスクIDと日付に紐づけて保存する
