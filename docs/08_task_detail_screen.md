# 08 タスク詳細画面

## 概要
サブタスクの進捗入力・時間チップ入力・コントリビューショングラフを1画面に統合表示する、本アプリの中心となる画面を実装する。

## 詳細要件
- ヘッダー: タスクタイトル、全体進捗(パーセンテージ＋進捗バー)を表示する
- サブタスク一覧: 各サブタスクの名称、重み(%)、進捗スライダーを表示する
- サブタスク追加ボタンを配置する
- 時間チップ入力UIを配置する
- コントリビューショングラフを配置する
- 03(サブタスク管理)・04(進捗計算)・05(時間チップ)・06(グラフ)の各機能を統合する
